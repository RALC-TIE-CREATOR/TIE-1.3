- **B5 (μ(x)):** `μ(x) = x/√(1+x²)` is derived from renewal statistics with `p = 2` and `β = γ`; the empirical contrast is B6 (Vol. III).
- **B6 (SPARC):** with `a_tr` frozen, the TIE form wins in the relative band (124 galaxies / 3039 points).
- Mass relations remain an ansatz; the full topological derivation is an open front.
